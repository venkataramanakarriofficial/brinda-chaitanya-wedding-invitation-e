# Brinda & Sai Chaitanya — Next.js Wedding Invitation

A responsive, cinematic invitation built with Next.js 16 and React 19.

## Experience

- Original eight-second opening film plays automatically with no captions, controls or overlays
- The supplied Jashn-E-Bahaaraa flute instrumental starts with the opening film and continuously loops only the 00:14–00:54 segment
- Gentle automatic scrolling begins after the opening film and stops immediately when a visitor takes control
- Poetic but clear invitation copy from Brinda and Sai Chaitanya
- Family blessings, Muhurtham details, countdown, calendar download, directions and sharing
- Three original premium wedding images created specifically for the invitation
- Responsive layouts, custom icons and reduced-motion support

## Local preview

Run `npm install` once, then use `npm run dev` or double-click **START_INVITATION.cmd**. Both commands start the Next.js app at **http://localhost:3002/** and automatically open a dedicated Chrome window where the opening video and music can autoplay together.

The opening video starts immediately and the supplied music starts with it whenever the browser permits audible autoplay. The dedicated launcher enables zero-click playback; in a regular browser that blocks audible autoplay, the first interaction starts the music without interrupting the film. Music continues through the invitation, loops from 14 seconds to 54 seconds, and respects the visitor's play/pause choice.
